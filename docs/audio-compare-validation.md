# 음원 비교 차트 수정 — 2026-09-18

## 추가 확인

- 사용자가 원본 및 DDSP-SVC 음원을 다시 불러온 상태에서 실제 두 스펙트로그램 표시와 재생을 확인했다.
- 52초 탐색에서 두 파형의 재생 위치가 51%로 표시되어 전체 1분 41초 시간축과 일치함을 확인했다.
- 재생 버튼·파일 선택·음원 이름(파일명)·후처리를 한 줄 중앙 정렬했다. 브라우저 좌표 측정에서 재생 버튼 왼쪽과 파형 왼쪽 오차 0px, 후처리 오른쪽과 파형 오른쪽 오차는 부동소수점 수준(0.00002px 미만)이다.
- 재생 버튼과 파일 선택 버튼을 같은 30x30px 크기로 맞췄다. 파일명은 음원-1/음원-2와 같은 11px, 600 weight, 같은 색상으로 표시됨을 computed style로 확인했다.
- 사용자 화면 확인 완료. 후처리 왕복·저장 UI 종단 재검증은 아직 수행하지 않았다.

## 변경

- 300개 flex 막대의 최소 너비와 gap 누적으로 파형이 잘리던 문제를 비교 화면 전용 SVG viewBox로 수정했다.
- 각 파형은 자기 파일의 전체 길이를 창 너비에 맞추며, 재생 위치는 공유 시간 / 해당 파일 길이로 계산한다.
- 기존 전체 평균 주파수 막대를 시간별 STFT 스펙트로그램으로 교체했다. 2048점 Hann 창, 채널별 파워 평균, 공통 -100~0 dBFS 색상 범위를 사용한다.
- 긴 파일은 시간 열마다 겹치는 창들을 평균한다. 계산을 나눠 실행하고 입력 변경/언마운트 시 중지한다.
- 후처리 버퍼를 저장하면 파형과 스펙트로그램을 다시 계산한다.
- 작은 화면은 본문만 스크롤하고 하단 탐색/저장 버튼을 유지한다.

## 확인 결과

- 수정 전 사용자 브라우저에서 두 시험 파일과 재생, 일시정지, 52초 탐색 확인.
- 수정 후 데스크톱 차트 배치, 390×700 및 390×420 화면에서 스크롤과 하단 버튼 접근 확인.
- 타입 검사, 프로덕션 빌드, 기존 백엔드 테스트 18개 통과(음원 비교 저장 포함).
- Hann 창 보정 FFT의 0.5 진폭 정현파가 -6.0206 dBFS에 해당하는지 수치 검증.
- Chrome 확장 파일 URL 접근 권한이 없어 수정 후 파일 재입력 자동화가 차단됨. 실제 파일 차트, 후처리 왕복, 재생/탐색/저장 UI 종단 재검증은 보류. HMR로 기존 선택 파일 상태가 초기화되었으므로 다시 선택해야 한다.
- 390×420 검사는 키보드에 의해 줄어든 높이를 모사한다. 실제 모바일 가상 키보드 검증은 수행하지 않았다.
