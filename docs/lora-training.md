# LoRA 학습

내 곡으로 YuE2의 **사운드(NAR) LoRA**를 직접 학습하는 기능입니다("LoRA 관리" → "학습" 탭). 학습은 ComfyUI의 [ComfyUI-YuE2-Trainer](https://github.com/Starnodes2024/ComfyUI-YuE2-Trainer) 노드를 앱이 API로 돌립니다. 작곡(AR) 쪽은 학습하지 않습니다.

> 라이선스: YuE2 모델 가중치는 CC BY-NC 4.0이라 학습 결과도 **비상업용**입니다. 학습기 저장소의 라이선스 표기는 "other"(NOASSERTION)이고, 한 포크의 README에는 Apache-2.0으로 적혀 있습니다. 배포할 때는 원본 저장소에서 조건을 확인하세요.

## 준비

1. ComfyUI를 `engine/ComfyUI`에 설치하고(자세한 방법은 [comfyui-setup.md](comfyui-setup.md)), 설정의 ComfyUI 주소가 실제 실행 주소와 같아야 합니다(예: `http://127.0.0.1:8190`).
2. `engine/ComfyUI/custom_nodes/`에 ComfyUI-YuE2-Trainer를 넣습니다.
3. `engine/ComfyUI/models/checkpoints/`에 BF16 체크포인트 `yue2_3b_bf16.safetensors`(약 7.8GB, Comfy-Org/YuE2)를 넣습니다. 학습기는 이 파일이 필요합니다.
4. "학습" 탭 위쪽의 준비 상태 표시가 모두 초록이면 시작할 수 있습니다.

## 순서

1. **곡 폴더**: 입력란에 경로를 쓰거나 "찾기"를 누릅니다. 찾기 창은 `library/Lora`에서 시작하고, 폴더를 한 번 클릭하면 선택, 더블 클릭하면 안으로 들어갑니다. "이 폴더 선택"을 누르면 곡을 바로 읽어 옵니다(mp3/wav/flac, 같은 이름의 `.txt`가 있으면 캡션으로 사용).
2. **곡 선택**: 곡마다 체크박스와 길이가 나오고, 체크한 곡만 학습합니다("모두 선택/해제").
3. **옵션**: 이름, 트리거 단어(영문 소문자·숫자·밑줄), 조각 길이(2~10초 직접 입력, 비우면 6초), 크기(rank 16 / 32, 기본 16), 끝내는 조건(스텝 수 또는 곡 전체 반복 횟수). 화면에 스텝, 반복 횟수, 조각 수, 예상 시간(이 PC 기준 스텝당 약 0.85초)이 함께 나옵니다.
4. **학습**: 진행률과 남은 시간이 나오고 취소할 수 있습니다. 취소해도 서버는 안전하게 남습니다.
5. **결과 선택**: 학습이 끝나면 EMA와 raw 두 파일 차이를 자동으로 재서(상대 차이 1% 미만이면 같다고 판단) 다르면 A/B 시험곡을 만들어 들어 보고 고르게 합니다. 같으면 시험곡 없이 바로 확정합니다.
6. **확정**: `library/Lora/<이름>/`에 파일과 `학습 기록.json`(설정, 곡 수, 학습 시간)이 저장되고, `models/yue-adapters/<이름>/`에 설치본이 하드 링크로 만들어져 "Installed" 탭에 나타납니다(다른 드라이브면 복사).
7. **보관함**: 학습 탭 아래 목록에서 이름·메모를 수정하고(설치본에도 반영), 삭제할 수 있습니다(보관함과 설치본이 함께 지워짐).

## 값의 의미

- **스텝**: 곡에서 무작위로 자른 조각 하나로 한 번 학습하는 단위입니다. 효과를 결정하는 것은 스텝 수입니다.
- **곡 전체 반복**: 스텝 ÷ 조각 수로 구한 참고값입니다. 곡이 짧아도 스텝이 충분하면 음색을 배웁니다. 다만 곡이 적으면 같은 조각을 여러 번 보게 되어 외울 위험이 있어, 스텝이 1000 미만이면 효과가 약할 수 있다는 경고와 곡 전체 30번 초과 반복이면 외울 수 있다는 경고를 보여 줍니다.
- **조각 길이**: 이 PC(RTX 5070 12GB)에서는 6초까지 됩니다. 8초는 VRAM 부족으로 실패했습니다.

## 실측 결과 (RTX 5070 12GB)

| 학습 | 곡 | 스텝 | 곡 전체 반복 | 결과 |
|---|---|---|---|---|
| 지수 음색 | 4곡(12분) | 1500 | 약 12.5회 | 적용 효과 확인 |
| 김현식 rank16 / rank32 | 17곡 | 1500 | 약 2.2회 | 두 크기의 측정값 차이 없음 → 이후 rank 16 사용, 여성 보컬에 적용했을 때 "약간 굵은 목소리"로 변함 |

EMA와 raw의 상대 차이는 모든 학습에서 0.0045~0.0065%였습니다. 이 값은 `scripts/lora_compare.py`(ComfyUI 가상환경의 python으로 실행)로 잽니다.

## API

`/api/lora-train/*`: `GET status`, `GET library`, `GET browse?path=`, `POST scan`, `POST start`, `POST cancel`, `POST ab`, `POST finalize`, `POST discard`, `GET ab/(ema|raw)`, `PATCH·DELETE library/:name`. 자세한 내용은 [local-api.md](local-api.md)를 보세요. 구현은 `backend/lora-train.mjs`(요청 검증, 프롬프트 생성, 폴더/보관함 함수)와 `backend/lora-trainer.mjs`(실행, 진행률, 취소, 확정)이고, 테스트는 `backend/lora-train.test.mjs`입니다.
